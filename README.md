## Prova de Web Development — FIAP

Projeto desenvolvido para uma prova da disciplina de Web Development, com o objetivo de identificar e corrigir 20 erros no código fornecido pelo professor.

# Tecnologias utilizadas
HTML
CSS
JavaScript

# Objetivo
Corrigir os erros do código original, garantindo o funcionamento correto da aplicação e aplicando os conhecimentos desenvolvidos durante as aulas.
